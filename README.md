# K-Games 2
Native 3D Vulkan Game Engine Suite built on **Godot Engine 4.7 (Vulkan Forward+ Rendering)**.

## Features
- Native Vulkan Hardware Acceleration (Direct3D 12 / Vulkan Driver Pipelines)
- True 3D Topographic Mesh Relief & PBR Materials
- 3D Dynamic Lighting, Shadows & Particle Effects
- Free Orbit Camera & Tactical Pan Controls
- 10 Modulare 3D-Spiele: Schach, Risiko, Schiffe versenken, Civilization, Mensch ärgere dich nicht, Monopoly, Kniffel, Lotti Karotti, Katan & Scotland Yard
- Automatische Multiplattform-Builds: Standalone Windows Desktop 64-bit EXE (vollständig eingebettete PCK-Ressourcen) und Android APK
